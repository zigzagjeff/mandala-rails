App landscape for Mandala Chart / Mandalart / Lotus Blossom 9x9 grid tools, organized by platform and category

Canonical / official lineage — mobile + web
official

MandalaChart Official

iOS · Android · Web (mandalachart.com)

Matsumura's own app. 9x9 + 3x3 modes, Google Drive sync, image export, AI generation (beta). Life Plan template included. One-time purchase.

indie

Mandal-Act

iOS

Clean execution on the grid concept. Color-coded sections, widget support, weekly/monthly action tracking. One-time purchase, no subscription.

indie

Goal Sheet (Mandalart Maker)

iOS

Straightforward 9x9 with checkmark completion. Calls itself "Goal Bingo" — distanced from the brand intentionally.

indie

MyManda

iOS

Rides the Ohtani wave. Korean-origin, multilingual. Simple grid implementation.

indie

Mandalart Planner

iOS

Hierarchical sub-board system, real-time progress tracking. 7-language support. Released 2024–2025.

web

your-mandalart.vercel.app

Web (open source, Vercel)

Lightweight, no-account webapp. Simple 9x9 grid, deploy-your-own. Early-stage indie.

Facilitation / whiteboard — Lotus Blossom framing
web

Miro

Web · Desktop

Template library includes both "Mandala Chart" and "Lotus Diagram." Collaborative, infinite canvas. Treats it as a brainstorming format, not a goal-setting tool.

web

Creately

Web

Lotus Diagram template with real-time collab. Strong design-thinking positioning. Export to PDF/PNG/SVG.

web

Visual Paradigm Online

Web

Dedicated "Lotus Diagram" tool with pre-built templates. Leans toward enterprise diagramming (UML, ERD family). Lotus Blossom is a first-class diagram type here.

web

EdrawMax Online

Web · Desktop

Explicit "Lotus Diagram" support with example gallery. Similar to VP — diagramming suite that includes the format.

PKM / local-first — plugin & template ecosystem
plugin

Obsidian — Mandala Grid

Obsidian community plugin (pending review)

PR open in obsidian-releases (#10067). Not yet in the community registry. Early but real. Developer: panAtGitHub.

template

Notion Marketplace

Notion templates

Multiple "Mandala Chart" templates available, including a dedicated "New Year Goal Planning" one. Grid is simulated via table/database layout — not native.

Adjacent / hybrid — GTD+grid, habit execution
indie

Mandalart → GTD app (DEV.to)

iOS (React Native, indie)

Converts handwritten 9x9 grids via OCR (OpenCV + AI) into a GTD task list. Bridges planning ↔ execution. Built with Claude Code — notable indie build.

web

Routinery

Web · iOS · Android

Habit/routine execution app that explicitly markets Mandalart chart templates as an intake pathway. Not a 9x9 tool itself — it's the execution layer after you plan.
